Hướng Dẫn Chia Sẻ Link Cổng Phụ Huynh Đúng Cách

• Tại sao link có chữ "blob:" bị lỗi? Link bắt đầu bằng chữ blob: là đường link ảo tạm thời khi xem trước. Phụ huynh ở máy khác không thể mở link này.

• Cách gửi chuẩn cho phụ huynh:

  1. Tải tệp index.html về máy tính.
  2. Đưa tệp lên trang web miễn phí (như tiiny.host hoặc app.netlify.com/drop) để lấy một đường link thật (ví dụ: https://lop2a7.tiiny.site).
  3. Vào tab Cổng phụ huynh bấm "⚙️ Đổi Link Web Lớp" và dán link đó vào. Khi đó, nút Sao Chép Link sẽ tạo link chuẩn 100% cho từng phụ huynh mở bằng Zalo!
  4. Nếu chưa có link web thật, bố mẹ chỉ cần mở tệp hoặc vào trang lớp rồi nhập mã con (vd: HS01) ở ngay màn hình đầu tiên là xem được ngay!
🌐

Cài Đặt Đường Link Web Thật

Dán đường link trang web lớp học của cô giáo sau khi tải lên mạng (Tiiny.host, Netlify, Github, tên miền trường...):

💡 Sau khi lưu, nút "Sao chép link Zalo" sẽ tự động gắn đường link web này kèm mã con (vd: https://lop2a7.tiiny.site/?ph=HP-HS01) để phụ huynh mở được 100% trên điện thoại!
